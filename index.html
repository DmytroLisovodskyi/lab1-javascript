Застосування JavaScript для розв’язання прикладних задач

Функція triangle() призначена для розв’язання прямокутного трикутника за двома заданими параметрами.

Відкрийте консоль браузера клавішею F12 або Ctrl + Shift + J та виконайте тестові запуски.

Формат виклику:

triangle(значення1, "тип1", значення2, "тип2")

Доступні типи:

  • leg — катет
  • hypotenuse — гіпотенуза
  • adjacent angle — прилеглий кут
  • opposite angle — протилежний кут
  • angle — гострий кут при заданій гіпотенузі

Приклад:

triangle(7, "leg", 18, "hypotenuse");
